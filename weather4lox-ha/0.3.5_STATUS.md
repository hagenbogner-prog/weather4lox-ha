# Weather4Lox HA 0.3.5

## Changes

- App version raised from 0.3.4 to 0.3.5.
- Added `server_035.py` compatibility layer while retaining the 0.3.4 forecast engine.
- Normalize temperature, wind speed, pressure and precipitation units for the Loxone response.
- Convert cardinal wind directions to degrees.
- Use the configured timezone offset instead of a hard-coded `0`.
- Preserve sunrise/sunset when exposed by the Home Assistant weather entity.
- Keep the existing 29-column Loxone format-2 validation and diagnostics.

## Git delivery

The changes are committed directly to `main` so the Home Assistant app repository can consume the new version through `weather4lox-ha/config.yaml`.
